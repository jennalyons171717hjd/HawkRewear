How bidding and local drop-off work

HawkRewear is built around the handoff. Bid online, then meet a neighbor, use a drop-off point, or ask for shipping. Local choices cost nothing.

Bidding

Open for 72 hours

Each auction runs three days. A bid in the last five minutes adds five minutes, so nobody gets sniped.

Buy now option

Sellers can set a fixed price. Buying it ends the auction immediately.
